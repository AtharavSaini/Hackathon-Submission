# FinSight AI

FinSight AI is a full-stack web application that helps users explore suitable loan and investment options based on their financial profile. The platform collects user information through an interactive questionnaire and provides personalized recommendations using a Flask-powered backend.

**Live Demo:** https://projectfinsight.netlify.app/

**Backend API:**  https://hackathon-submission-uzgw.onrender.com

---

## Overview

The application is designed to simplify the process of evaluating different financial options. Users provide relevant financial information, and the system processes the data to generate personalized recommendations for different loan categories and investment opportunities.

---

* Education Loan Recommendation

## Workflow

1. The user selects a loan or investment category.
2. The application collects financial information through a guided questionnaire.
3. The frontend sends the data to the Flask backend through REST APIs.
4. The backend processes the information using dedicated recommendation engines.
5. The generated recommendation is returned and displayed to the user.
